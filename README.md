# Para Sofía, mi bebé ♡

Una pequeña sorpresa de Joako para Sofía: seis corazones para descubrir mensajes de amor y una carta al terminar. Sin límite de tiempo; los mensajes se pueden volver a leer y el juego se puede reiniciar.

## Abrir la página

Es una web estática, sin instalación ni dependencias. Abre `index.html` o publícala con GitHub Pages desde la rama `main`, carpeta raíz `/`.

Dirección prevista de GitHub Pages: https://joakovrd-designer.github.io/TE-AMO-MI-SOFI/

## Personalizar

- Los seis mensajes están en `app.js`.
- La bienvenida y la carta están en `index.html`.
- Los colores y el diseño están en `styles.css`.

El diseño se adapta al celular, permite jugar con teclado y respeta la preferencia de movimiento reducido. Las fuentes y los dibujos forman parte de la propia página; no necesita servicios externos para jugar.
